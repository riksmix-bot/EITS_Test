# Tõendusmaterjali nimekiri (E-ITS / EITS)

## 1. Repositoorium (kood ja konfiguratsioon)

- Turbenõuded / reeglid (nt `rules/`)
- Autentimine/autoriseerimine (konfiguratsioon + arhitektuurikirjeldus)
- Logimine/auditilogimine (vt ka eraldi logimise protsess)
- CI/CD pipeline konfiguratsioon
- Haavatavuste skaneerimine (konf + raportid)
- Infrastruktur-as-code (kui olemas)

## 2. Identiteet ja ligipääsud

- Kasutajate/rollide mudel
- Ligipääsutaotluste protsess ja näidised (valim)
- Privilegeeritud ligipääsude haldus (admin, break-glass)

## 3. Muudatuste haldus (Change)

- Muudatuse taotluse mall
- Heakskiidu logi (kes/ millal)
- Release notes / deploy logid
- Tagasipööramise (rollback) kord

## 4. Logimine, monitooring, alertid

- Auditilogide formaat ja näidis (punastatud)
- Rakenduslogide poliitika
- Dashboardide/alertide nimekiri
- Kriitiliste sündmuste detekteerimine

## 5. Varundus ja taaste

- Varunduse poliitika (RPO/RTO)
- Varunduse edukuse raportid
- Taastetestide protokollid/raportid

## 6. Intsidentide käsitlus

- Intsidendiprotsess
- Rollid ja kontaktid
- Viimaste intsidentide valim (punastatud)
- Lessons learned / parandusmeetmed

## 7. Tarnijad ja teenusepakkujad

- Teenusepakkujate nimekiri
- Turbenõuded lepingutes / SLA
- Auditiklauslid / tõendid (ISO, SOC2, jne kui olemas)

## 8. Riskijuhtimine

- Riskiregister
- Riskihindamise metoodika
- Riskide aktsepteerimised (kes, millal)

## 9. Füüsiline turve (kui kohaldub)

- Serveriruumi ligipääsu kord
- Külastajate logi
- Seadmete inventuur ja märgistus
