# E-ITS (EITS) auditi materjalid

See kaust sisaldab auditi ettevalmistuse ja tõendusmaterjali **mal­le**, mida saab täita mis tahes infosüsteemi/teenuse kohta.

## Kuidas kasutada

1. Täida `auditiplaan.md` (skoop, rollid, ajakava, allikad).
2. Täida `meetmete-maatriks.md`:
   - kui E-ITS meetmete kataloog on olemas, pane “E-ITS viide/ID”
   - kui kataloogi pole, kasuta “Kategooria” ja lisa viide hiljem
3. Koosta protsessikirjeldused kausta `protsessikirjeldused/` (soovituslikult 1 protsess = 1 fail).
4. Koonda tõendid `toendusmaterjali-nimekiri.md`-i (failiteed, raportid, lingid, ekraanipildid).
5. Koosta `lunkade-ja-parandusplaan.md` (prioriteet, risk, vastutaja, tähtaeg).

## Reeglid

- Ära lisa siia kausta **tundlikke andmeid** (saladused, tokenid, isikuandmete väljavõtted).
- Tõendusena eelista **konkreetseid viiteid** (repo failitee, konfiguratsiooniplokk, CI töö tulemus).
