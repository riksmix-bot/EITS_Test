# Meetmete maatriks (E-ITS / EITS)

## Kasutusjuhis

- Täida 1 rida = 1 meede/kontroll.
- Kui E-ITS viide/ID pole teada, täida “Kategooria” ja lisa ID hiljem.
- “Tõendus” peab olema **kontrollitav** (konkreetne failitee, raport, konfiguratsioon, ekraanipilt, logi väljavõte).
